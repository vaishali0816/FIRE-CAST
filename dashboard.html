Why MAE over RMSE? Daily active-fire counts follow an extreme zero-inflated, long-tailed distribution. While RMSE squares the errors (meaning 1 extreme autumn firestorm day dominates 90% of the score), MAE provides an unskewed, operationally actionable measure of average daily count discrepancy.

Top Feature Importances (Random Forest)

1. Label Definition

Target y_{t+1} is the total count of MODIS/VIIRS thermal pixels inside California with confidence ≥ 30% over 24h UTC.

2. Cloud Obscuration Effects

Thermal sensors cannot penetrate clouds. Fires burn undetected on overcast days (false drop), creating an artificial surge the next day when clouds clear.

3. Missing Data vs. Zeroes

Polar satellites pass 2-4 times/day. Missing swaths or sensor dropouts must be marked as missing, not assumed to be 0 active fires.

4. Honest Reporting Verdict

ML beats persistence overall. But on 70% of days (quiet winter/spring), persistence is nearly unbeatable. ML wins by anticipating rapid wind-driven breakouts.
